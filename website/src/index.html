Why I built it

I run a lot of Claude Code sessions at once: a bug fix in one repo, a refactor in another, a quick question in my home folder. Then I close the terminal, and the next day I can't find any of them.

The sessions aren't actually gone. I dug in and found three things:

  1. Every session is saved. Claude Code writes each one to ~/.claude/projects/<folder-name>/<session-id>.jsonl, including the folder it ran in and an auto-generated title.
  2. claude --resume only shows the current folder. If you don't remember where you started a session, you have to cd into folders one by one until it shows up.
  3. Old sessions are deleted. By default Claude Code removes sessions after 30 days (the cleanupPeriodDays setting).

So I wrote a small CLI that reads all of those files at once, and then wrapped it in a menu bar app so that getting back into a session is one click: newest at the top, oldest at the bottom, no folders to think about.

How it works

  1. 1

    Read

    Scans every *.jsonl file under ~/.claude/projects, plus its own backup archive.

  2. 2

    Index

    Pulls out the title, the folder the session ran in, git branch, first and latest message, and last activity. Results are cached by file size and modified time, so a refresh takes about 30 ms.

  3. 3

    Reopen

    When you click, it opens a new terminal window and runs cd <that folder> && claude --resume <id>. Claude Code loads the full conversation back.

It only reads session files. It never edits them, and nothing leaves your Mac unless you ask for an AI summary (see the FAQ).

What it does

Newest first, every folder

One timeline grouped by Today, Yesterday and earlier dates. You never pick a folder: each session remembers where it ran.

One click, new window

Each session opens in its own terminal window, titled with the session name so you can tell them apart.

Menu bar dropdown

Your 5 to 20 most recent sessions are always one click away in the macOS menu bar, even with the main window closed.

Side by side

Tile every open terminal window into a neat grid on your screen, on demand or automatically after each open.

Search

Filter by title, message text or folder as you type. Press Enter to open the top match.

Themes

System, Light, Dark, Paper, Solarized, Midnight, Nord and Rosé, plus accent colours, three text sizes and three densities.

Keeps sessions past 30 days

cs backup copies session files to an archive so Claude Code's cleanup can't delete them. Archived sessions are restored automatically when you open them.

Optional AI recaps

cs summary asks Claude Haiku for a 2–3 sentence recap of what a session did, cached locally.

Your terminal, your flags

Terminal, iTerm2 or Ghostty. Add extra arguments such as --model opus to every resume.

Install

The app (Apple Silicon Mac)

  1. Download Claude-Sessions-macOS-arm64.zip and unzip it.
  2. Move Claude Sessions.app to your Applications folder.
  3. The app isn't signed with an Apple developer certificate yet, so macOS will block the first launch. Clear the quarantine flag once: 
    xattr -dr com.apple.quarantine "/Applications/Claude Sessions.app"
  4. Open it. The first time you click a session, macOS asks whether Claude Sessions may control Terminal. Click Allow; that's how it opens windows.

Needs Claude Code installed (claude on your PATH) and macOS 11 or later. Python 3 ships with macOS's command line tools.

Just the CLI (macOS or Linux)

One Python file, no dependencies:

mkdir -p ~/.local/bin
curl -fsSL https://raw.githubusercontent.com/AryaKesharwani/claude-sessions/main/cs.py -o ~/.local/bin/cs
chmod +x ~/.local/bin/cs
cs

Make sure ~/.local/bin is on your PATH. If fzf is installed, cs uses it for fuzzy picking.

Build the app from source

git clone https://github.com/AryaKesharwani/claude-sessions
cd claude-sessions/app
pnpm install
pnpm tauri build   # → src-tauri/target/release/bundle/macos/Claude Sessions.app

Needs Rust (1.77+) and Node 18+. This is also the way to get an Intel build.

CLI reference

CommandWhat it does
csInteractive picker. Type a number to resume, or words to narrow the list.
cs ls [words] [-n 25] [--here] [--json]List sessions newest first. --here limits to the current folder; --json prints everything the index knows.
cs r <number|id> [--claude-args "…"]Resume a session by list number or id prefix, in its original folder.
cs show <number|id> [-n 8]Print the last few messages you sent in a session.
cs summary <number|id>Write and cache a short AI recap using claude -p --model haiku.
cs pin <number|id>Pin or unpin a session to the top of cs ls.
cs backup [-q]Copy new or changed session files to ~/.claude-sessions/archive.

Tip: to back up automatically, add cs backup -q as a SessionEnd hook in ~/.claude/settings.json, or raise cleanupPeriodDays there.

FAQ

Does it send my code or conversations anywhere?

No. Listing, searching and opening are all local file reads. The only exception is cs summary, which you run yourself: it sends the messages you typed in that one session (not Claude's replies, not your files) to Claude Haiku through your own claude CLI login, with tools turned off and session saving disabled.

Will it change or break my sessions?

It never writes to Claude Code's session files. Resuming is done by Claude Code itself with claude --resume. The only time it writes into ~/.claude/projects is to copy an archived session back so Claude Code can resume it.

Why does macOS ask to let it control Terminal?

Opening a new Terminal or iTerm2 window and running a command in it is done with AppleScript, which macOS gates behind the Automation permission. You can change it any time in System Settings → Privacy & Security → Automation.

Why is the app unsigned?

Signing and notarising needs a paid Apple developer account, which this side project doesn't have yet. The full source is in the repo and the release is built from it; you can also build it yourself in about two minutes.

Does it work on Intel Macs, Linux or Windows?

The download is for Apple Silicon. Intel Macs can build from source. The cs CLI works anywhere Python 3 and Claude Code run. The app's terminal integration is macOS only for now.

A session says "archived". What does that mean?

Claude Code already deleted it after 30 days, but a cs backup copy exists. Opening it restores the file first, then resumes it as usual.

Is this made by Anthropic?

No. It's an independent open-source tool that reads the files Claude Code already writes. Claude and Claude Code are Anthropic's products.
